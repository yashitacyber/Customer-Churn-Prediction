# 📉 Customer Churn Prediction Machine Learning Web App

An end-to-end Machine Learning web application built with Python, Scikit-Learn, and Streamlit to predict customer churn risk and probabilities for telecommunication services.

## 🚀 Features
- **Predictive Modeling:** Uses a Random Forest Classifier to identify customers at high risk of leaving.
- **Probability Scoring:** Calculates the exact churn risk percentage.
- **Interactive UI:** Built with Streamlit for a clean, user-friendly interface.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Pickle
- **Frontend / Deployment:** Streamlit
